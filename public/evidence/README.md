# Evidence screenshots (drop-in)

Put real project screenshots here and the matching exhibit automatically
replaces its procedural placeholder art — no code changes needed.

**Naming:** `{projectId}-{evidenceId}.png` (or `.jpg` / `.jpeg` / `.webp`)

Current slots (from `lib/content.ts`):

- `saferoute-map` · `saferoute-risk` · `saferoute-pipeline`
- `noscalp-drop` · `noscalp-stampede` · `noscalp-schema`
- `photonest-library` · `photonest-arch` · `photonest-auth`
- `redditrecbuds-ranking` · `redditrecbuds-app` · `redditrecbuds-pipeline`

Images are shown at a 4:3 crop (`object-cover`) — landscape screenshots
around 1200×900 look best. Also: drop `dossier.pdf` in `public/` and the
"FULL DOSSIER (PDF)" button appears in the About section.
